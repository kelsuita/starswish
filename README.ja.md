# Starwish

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · **日本語**

> 欲しいものを書き留めて、少しずつ現実になっていくのを見守ろう。

Kotlin + Jetpack Compose で作られた Android の貯蓄目標アプリです。UI は **MIUIX 0.9.4** をベースに、HyperOS の設定画面とラージタイトルの操作感を参考にしています。ページ全体の横スワイプ、スクロールで折りたたまれるタイトル、アクセントカラーから導出されるフルカラーパレット、任意の背景ぼかしなどを備えています。

[ダウンロード](https://github.com/kelsuita/starswish/releases/latest) · [問題を報告](https://github.com/kelsuita/starswish/issues) · [愛発電で支援](https://afdian.com/a/kelsuita)

## はじめに

Starwish はお金には触れません。「いくら貯めたいか、あとどれくらいか、1日あたりいくら必要か」を計算し、毎日目に入る場所に表示することだけを行います。

複数の貯蓄目標を同時に管理でき、各目標の進捗を1つまたは複数の貯蓄口座に紐付けられます。ホームバナーには指定した目標が表示され、進捗バー、パーセント、1日あたりの推奨額が口座残高に合わせてリアルタイムに更新されます。金額はすべて整数の「分」で計算するため、`0.1 + 0.2` のような誤差は発生しません。

小星記帳（Xiaoxing Ledger）を使っている場合は、自分で口座詳細ページを開いたときだけ、画面に表示されている「人民元残高」を読み取り、確認後に目標へ同期できます。バックグラウンド同期は行わず、明細も読み取らず、自動で確定することもありません。

## クイックスタート

1. 端末のアーキテクチャに合う Release APK をダウンロードしてインストールします。不明な場合は `app-universal-release.apk` を選んでください。
2. 「口座」で口座を追加し、残高を入力します。小星記帳を使わない場合は完全に手動で管理できます。
3. 「ホーム」で願いを作成し、目標金額、紐付ける口座、進捗の計算方法を設定します。
4. 口座残高を更新して目標の進捗を確認します。テーマ、アクセントカラー、ホームバナーは「設定 → テーマ設定」で変更できます。

小星記帳の残高読み取りは任意機能で、アクセシビリティサービスを別途有効にする必要があります。初回は下の連携説明をお読みください。

## 機能

### 貯蓄目標

- 目標名、目標金額、任意の期限を設定。ホームバナー、進捗バー、アイコンはアプリのアクセントカラーに従います
- 各目標に1つ以上の貯蓄口座を紐付け、進捗率、貯まった金額、残り金額、1日あたりの推奨額を表示
- 進捗の計算方法は2種類：口座の**現在残高**で計算するか、目標作成時の残高**開始点**からの増加分で計算
- 進捗は 0%–100% に制限。複数目標の残高は合算されず、互いに占有もしません

### 貯蓄口座

- 口座の追加、編集、削除。目標に紐付いている口座は削除できません
- 小星記帳から現在残高を読み取り可能：自分でリクエストを開始した後、小星の口座詳細ページを開くと金額を自動認識し、Starwish に戻って確認後に同期します
- 読み取りは1口座・1回のリクエストのみ。2分以内に完了しない場合やページ情報が不明確な場合は停止します

### テーマと外観

外観オプション：

- テーマモード：システムに従う / ライト / ダーク
- ダークモードの純黒背景：ダークモードのみ有効。ページ背景が純黒になり、カードの階層は維持されます
- アクセントカラー：デフォルト、Monet、ブルー、グリーン、オレンジ、パープル
- パレットスタイルと Material 3 カラースペック（2021 / 2025）。MIUIX `ThemeController` がフルパレットを導出し、Monet カラーでも同様に適用されます
- ホームバナー：ライト / ダーク。バナーに表示する目標を指定可能。コンパクトな目標リスト
- 背景ぼかし：Android 13 以降で利用可能。ラージタイトルバーと下部ナビゲーションに適用
- 言語：システムに従う / 简体中文 / 繁體中文 / English / 日本語。設定ページ上部で即時切り替えでき、再起動は不要です。初回起動時はシステムに従います

背景ぼかしのスイッチは「設定 → 外観」にあり、その他の項目はテーマ設定ページにまとまっています。設定は端末内に保存され、再起動後も有効です。

### 操作とディテール

- ホーム、口座、設定の3ページを横スワイプで切り替え。タイトルと内容が一緒に動き、下部ナビゲーションは固定。各ページのスクロール位置は独立して保持されます
- 上部のラージタイトルはスクロールで折りたたまれ、リストが端に達するとバウンスします
- ホームバナー、目標カード、口座カードを Miuix の文字体系で再レイアウト。アプリアイコンはグラデーション背景＋星形のアダプティブアイコンで、Android 13 のモノクロレイヤー付きです
- 「このアプリについて」は独立ページで、GitHub、愛発電、使い方、データと権限の説明、進捗計算方法、公式ドキュメントへのリンクを含みます
- 設定ページ上部の一言は、簡体字または繁体字中国語の UI で有効な場合のみ表示されます。中国語 UI の初回は既定で有効で、「設定 → 外観 → テーマ設定 → ホーム」でオフにできます。中国語以外では自動的に非表示になりリクエストも停止し、中国語に戻すと以前の設定を保持します。有効でローカルに一言がない場合は公開 API から取得して保存します。ページ切り替えや再起動では既存内容を更新せず、タップで手動再取得できます

### JSON バックアップ

- 入口は「設定 → バックアップ → インポートとエクスポート」。外観グループの下、アプリグループの上です
- 口座、目標、外観設定、保存済みの一言をエクスポートし、システムのファイル選択で JSON として保存します
- インポート時は形式、バージョン、金額範囲、口座の関連を検証します。確認後、既存データを丸ごと置き換えるため、先に現在のデータをエクスポートすることを推奨します
- バックアップは平文で口座名と残高を含むため、安全に保管してください。最大 1 MB まで対応します
- 読み取り中の一時リクエスト、未確認の残高、システムのアクセシビリティ権限は含みません。端末変更後は権限を再度有効にする必要があります

## プライバシーとデータ

- すべての目標と口座データは端末のプライベート領域にのみ保存されます。アカウント、ログイン、広告、統計 SDK はありません
- 銀行カード番号、パスワード、完全な明細は読み取りません。タップ、送金、小星記帳データの変更は行いません
- 一言の取得が必要なとき、または手動更新をタップしたときのみ、中国語 UI で一言が有効な場合にリクエストします。中国語以外またはオフの場合はリクエストせず、口座、残高、目標情報を送信しません。GitHub、支援、公式ドキュメントのリンクを開くと外部アプリに遷移し、各サイトが処理します
- 小星の残高読み取りは Android のアクセシビリティサービスに依存します。限定されたアプリのパッケージ名と口座詳細ページのみを認識し、システム設定でいつでもオフにできます
- Android の自動バックアップとデバイス移行は無効です。手動で JSON バックアップをエクスポートできます。アプリをアンインストールするとローカルデータが削除されるため、事前にアプリ外へバックアップを保存してください

## 小星記帳との連携方法と範囲

確認済みの公式ドキュメント：

- URL Scheme：<https://cxincx.com/support/scheme.html>
- 暗号化バックアップの説明：<https://cxincx.com/support/backup/7.html>

プロジェクト連携時に確認したドキュメントによると、Scheme は明細の挿入と自動記帳ダイアログの起動を提供しますが、本プロジェクトで使える口座残高照会 API は提供しておらず、バックアップファイルも直接開いて読み取ることはできません。そのため現在の実装は、表示されたページから残高を認識する方式で、暗号化データベースの解析や、明細の累計値による残高の代替は行いません。

現在、ユーザーが自分で開いた**小星記帳の表示中の口座詳細ページ**を Android のアクセシビリティサービスで読み取ります：

1. 「口座」で貯蓄口座を追加します。名前は小星記帳と完全に一致させ、初期残高を入力します。
2. アプリ内の説明を読み、システム設定で「Starwish · Xiaoxingの口座を読み取る」を有効にします。
3. 口座カードで「Xiaoxingの残高を読み取る」をタップすると、小星記帳が開きます。
4. 2分以内に対応する口座詳細を開きます。サービスが `com.cxincx.xxjz.account.AccountDetailActivity` を検出すると自動でページを読み取り、完全な口座名と上部の「人民元残高」および数値が表示されていることを要求します。下部の明細にある過去残高は無視します。小星ページで追加のタップは不要です。
5. 読み取り成功後、小星ページ上部に「読み取りました。Starwish に戻ってください」カプセルが表示されます。タップすると Starwish の「口座」確認ページが開くので、認識金額を確認して「同期を確認」をタップします。カプセルは3秒後に自動でフェードアウトします。手動で Starwish に戻って未確認結果を確認することもできます。

上部カプセルは流体雲風のローカルなアクセシビリティオーバーレイで、OPPO のネイティブ流体雲ではありません。有効なサービスの `TYPE_ACCESSIBILITY_OVERLAY` を使用し、通常のオーバーレイ権限は要求せず、口座名や残高も表示せず、自動確認もしません。ネイティブの OPPO 流体雲にはプラットフォームサービスの認可、UPK テンプレート、SeedlingSupportSDK の連携が必要ですが、現在は未連携です。サービスが中断・破棄されるとカプセルは削除されます。タップは Starwish のコールドスタートとバックグラウンド実行の両方に対応します。ヒントは候補残高の認識・保存に成功した後だけ表示され、実機での読み取り連携テストの代替にはなりません。

**これはバックグラウンドのリアルタイム同期ではありません**。1回のリクエストは1口座のみで、候補結果を受け取るか2分でタイムアウトすると読み取りを停止します。明確な名前、残高ラベル、複数の異なる残高、クレジット枠、外貨、総資産概要などがある場合は認識を拒否します。手動更新は常に可能です。読み取れなかった場合はそのまま戻って残高を編集するか、再度読み取りを開始できます。権限が有効でない場合は読み取りを開始しません。

ユーザー提供の Activity 名と口座詳細のスクリーンショットに基づいて上部の人民元残高に適合し、明細の過去残高や金額が分離したノードを含む解析テストを追加しています。実機でのアクセシビリティノード連携結果はまだ取得していません。一部のページではアクセシブルなテキストが公開されない、または異なるラベルが使われる可能性があります。**スクリーンショットと解析テストは、実際の小星バージョンでの読み取り検証の代替にはなりません。**

ページ読み取りは小星のパッケージ名 `com.cxincx.xxjz` に限定されます。タップ、明細の変更、送金は行わず、スクリーンショットや完全なページテキストも保存しません。中国語 UI で一言が有効で取得・手動更新が必要なときのみ `v1.hitokoto.cn` へリクエストし、口座、残高、目標は送信しません。中国語以外またはオフの場合はリクエストしません。アプリは INTERNET 権限を持ち、バックアップとデバイス移行は無効です。システム設定からいつでもサービスをオフにできます。アンインストールするとアプリデータが削除されます。

Android 13 以降でファイルからアプリをインストールする場合、システムが先にアクセシビリティ権限を制限することがあります。その場合は本アプリのシステム「アプリ情報」メニューで、システムの案内に従って制限付き設定を許可してから手動で有効にしてください。権限は必ず端末ユーザーが確認する必要があります。

## ビルドとインストール

JDK 21、Android SDK Platform 37、ネットワークまたは依存キャッシュが必要です。Gradle Wrapper は同梱されています。最小対応は Android 8.0（API 26）、targetSdk 36 です。

Windows（ユニットテスト、debug APK のビルド、静的チェックを実行）：

```powershell
powershell -ExecutionPolicy Bypass -File tools\build.ps1
```

Android Studio でこのディレクトリを開き、Gradle を同期して実行することもできます。Android Studio はローカルの `local.properties` を自動生成しますが、このファイルはコミットしないでください。

Gradle タスクを直接実行することもできます：

```powershell
./gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

生成される debug パッケージ：`app/build/outputs/apk/debug/app-debug.apk`。

```powershell
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### 正式署名と release ビルド

リリース APK はプロジェクト専用の正式キーで署名され、Android デバッグ署名にはフォールバックしません。秘密鍵とパスワードを含むローカル設定はリポジトリに含まれません。新しい環境で正式版をビルドするには、安全なバックアップからキーを復元し、プロジェクトルートに `keystore.properties` を作成します：

```properties
storeFile=C:/secure/path/starswish-release.keystore
storePassword=YOUR_STORE_PASSWORD
keyAlias=starswish
keyPassword=YOUR_KEY_PASSWORD
```

`keystore.properties` は `.gitignore` で除外済みです。キーファイルもコミットしたり公開リポジトリへアップロードしたりしないでください。設定後、次を実行します：

```powershell
./gradlew.bat assembleRelease
```

署名済み APK は `app/build/outputs/apk/release/app-universal-release.apk` に出力されます。ローカル署名設定がない場合は未署名 APK が出力され、そのまま配布用インストールパッケージにはできません。独自キーでビルド・配布することは可能ですが、本プロジェクトの正式リリース APK を上書きインストールすることはできません。

リリース前に Android SDK Build Tools の `apksigner` で署名を確認できます：

```powershell
apksigner verify --print-certs app/build/outputs/apk/release/app-universal-release.apk
```

Build Tools ディレクトリを `PATH` に追加するか、フルパスを使用してください。正式版を保守する際は、署名証明書が既存の正式版と一致することを確認し、キーとパスワードの独立した安全なバックアップを保管してください。

## 検証

- `SavingsLogicTest`：金額精度と入力境界、紐付けた口座の計算、開始点からの計算、負数/超過進捗、残高ラベル、異なる口座、曖昧な結果、クレジット枠と外貨の拒否。
- `lintDebug`：静的チェック。依存バージョンは固定。バージョンアップ提案と KTX スタイル提案はビルドに影響しません。
- 上部カプセルは隔離エミュレータで補助アクセシビリティサービスを使い、実際のビルドのヒントコンポーネントを読み込んで、表示、自動消去、サービス停止時の削除、タップで実行中の Starwish に戻ることを検証しました。確認ページのコールドスタート入口も検証済みです。このコンポーネントテストは実際の小星の読み取りイベントを発生させておらず、実際の口座残高読み取りの連携テスト通過を意味しません。
- `tools/smoke-test.ps1`：現在のビルドをインストールし、専用の隔離エミュレータで口座追加、目標の必須入力検証、進捗計算、再起動後の永続化、権限の開示、このアプリについてページとシステム戻る、エッジ戻るジェスチャー、テーマ設定を検証します。指定したテストエミュレータの本アプリデータを消去するため、日常使いの端末では実行しないでください。
- `tools/start-test-emulator.ps1`：ローカルにある Android 35 x86_64 イメージで隔離テストエミュレータをポート 5580 で起動します。接続中の実機には触れません。テストスクリプトは指定した隔離エミュレータの本アプリデータのみ消去します。

## 既知の制限

- 小星記帳の残高読み取りは実機でのアクセシビリティノード連携が未完了です。バージョンによってページ構造が異なると認識に失敗する可能性があります
- ステータスバー背景の取得範囲と、タブ切り替え後に下部バーのぼかしが無効になる問題を修正済みです。Android 35 エミュレータでホスト GPU を使用して検証しました。他社製 OS と GPU での挙動は実機検証が必要です。詳細は [Miuix レビュー記録](docs/miuix-review.md) を参照してください
- 人民元の貯蓄口座のみ対応しています。多通貨、自動振替、資金配分は提供しません
- 正式 APK は現在プロジェクトによるサイドロード配布です。アプリストア配信フローは未設定です

```text
app/src/test/                          コアロジックのユニットテスト
tools/                                 ビルドと隔離エミュレータ検証スクリプト
```

### 言語パック

すべての UI 文言は安定した識別子（例 `home.current_wish`）を使い、実際のテキストは
`app/src/main/assets/i18n/`（`en`、`zh-CN`、`zh-TW`、`ja`）にあります。翻訳の追加・修正はこれらの
ファイルだけで完結し、Kotlin の変更は不要です。フラットなドット区切りキーはそのまま Crowdin に
アップロードできます。欠けたキーは英語、次に識別子自体へフォールバックします。アプリ名と
アクセシビリティサービスの名称/説明もビルド時に同じ言語パックから Android リソースへ生成されます
（Android がアプリ起動前に読み取るため）。言語を追加するには、`<言語コード>.json`（`en.json` を
コピー可）を同じディレクトリに置き、`Language.kt` の `AppLanguage` 末尾に項目を追加するだけです。
リソースディレクトリ、システム言語への追従、言語インデックスの範囲は自動で処理されます。保存済みの
選択は列挙インデックスで持つため、必ず末尾に追加してください。

同じ口座を複数の独立した目標に使えます。資金の自動配分や実際の振替は行いません。ホームバナーは
指定した1つの目標（既定は最初）の進捗のみ表示します。目標名、金額、日付の変更は開始点をリセット
しません。紐付ける口座や計算モードの変更は開始点を再設定します。
